# ritratti_delle_montagne
In questa repo c'è il materiale di un sito web "ritratti di montagne", sono attivi i link al catalogo, la tabella dati e le pagine degli item "Bestie da soma" e "17 Gennaio"
# materiale del sito:
1. homepage (index.html)
2. catalogo (catalogo.html)
3. tabella dati (dati_montagne.html)
4. pagine item ( bestie_soma_pg.html, 17_gennaio_pg.html)
5. metadati item (cartella metadati)
6. foglio di stile impiegato per l'intero sito (style/style.css)
7. immagini richiamate nel sito (cartella img)
8. tabella metadati ( ritratti_montagne.csv, ritratti_montagne.json)
